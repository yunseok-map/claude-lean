# A/B 실측 — 같은 과제, lean ON/OFF

2026-08-04 측정. 값은 전부 트랜스크립트의 `usage` 합산이며, 산출한 비용이 CLI가 보고한
청구액(`total_cost_usd`)과 소수점까지 일치함을 확인했다.

## 조건

동일한 저장소 복사본, 동일한 프롬프트, 동일한 모델로 `claude -p` 세션을 두 번 돌렸다.
차이는 `.claude/lean.config.json`의 `enabled` 하나뿐이다.

- 대상: Node/TS 프로젝트 115파일 / 32.9k줄
- 모델: Opus 5
- 과제: 데이터 흐름 조사 → 복구되지 않는 실패 지점 3곳 지목(파일:줄) → 최소 수정 제안 → `REPORT.md` 작성
- n=1

## 결과

| 항목 | A (lean OFF) | B (lean ON) | 차이 |
|---|---|---|---|
| 청구 비용 | $3.330 | $1.625 | **−51.2%** |
| 최대 컨텍스트 | 171k | 81k | −52.6% |
| 툴 결과 유입량 | 245KB | 65KB | −73.5% |
| 캐시 read 누적 | 2,238k | 1,033k | −53.8% |
| 출력 토큰 | 25k | 17k | −32.0% |
| 소요 시간 | 408초 | 280초 | −31.4% |
| 캐시 적중률 | 93% | 94% | 동일 |
| 툴 호출 수 | 26회 | 27회 | +3.8% |
| 전체 통독 | 7회 | 0회 | −100% |

## 무엇이 차이를 만들었나

툴 호출 횟수는 오히려 B가 하나 많다. **일을 덜 한 게 아니라, 한 번의 호출이 컨텍스트로
끌어온 양이 달랐다.**

- A는 구조를 훑자마자 파일 5개를 통째로 읽고, 그 무게를 세션 끝까지 지고 갔다.
- B는 `Grep`에 `head_limit`을 걸어 좌표부터 잡고, 이후 모든 `Read`에 `offset/limit`을 붙였다.
- 캐시 적중률은 93% 대 94%로 같았다. 적중률이 아니라 **적중시켜야 할 덩어리의 크기**가 달랐다.

## 품질은 유지됐나

두 세션이 독립적으로 지목한 결함 3개는 사실상 동일했고, 지목 위치는 원본 코드에서 직접 확인했다.

| 결함 | A 지목 | B 지목 |
|---|---|---|
| SSE 재연결 후 상태 재동기화 없음 | `app.js:3256` · `:1160` | `app.js:3279` · `:3256` |
| 초기 구간 예외가 기록되지 않고 청소도 안 됨 | `runner.ts:73~194` | `runner.ts:195` · `state.ts:540` |
| 자동 이어하기 가드를 시도 *전*에 영구 기록 | `server.ts:771` · `:786` | `server.ts:771` |

분량은 A 314줄 / B 226줄. 차이는 결함 개수가 아니라 배경 서술과 부록의 길이였다.

## 한계 — 이 숫자를 어디까지 믿을지

- **이번 절감은 전부 세션 카드에서 나왔다.** 컨텍스트가 최대 81k(8%)에 머물러 신호 훅은
  0회 발동했다. 즉 측정된 것은 작업 방식 지침의 효과이고, 신호·억제 로직의 효과는 포함되지 않았다.
- **n=1이다.** 에이전트는 같은 프롬프트에도 탐색 경로가 갈린다. 51%라는 값보다 "통독 7회 대 0회"라는
  메커니즘 차이가 재현 가능성이 높은 부분이다.
- **B도 지침을 완벽히 따르지 않았다.** 병렬 배치 0개, `cat`으로 파일 3개 동시 열람 1회.
  상한이 아직 남아 있다는 뜻이다.
- **탐색 위주 과제에 유리한 조건이다.** 파일 한두 개를 고치는 편집 위주 작업이라면 통독할 것 자체가
  적어 차이가 줄어든다.
- 서브에이전트는 양쪽 모두 0회였다. 읽은 코드가 최종 판단까지 계속 필요한 과제라, 위임 기준상
  직접 하는 것이 맞는 작업이었다.

## 재현

```bash
# 같은 저장소 복사본 두 벌을 만들고 각각에 설정을 넣는다
echo '{"enabled": false}' > armA/.claude/lean.config.json
echo '{"enabled": true}'  > armB/.claude/lean.config.json

# 같은 프롬프트로 각각 실행
cd armA && claude -p "<과제>" --output-format json > ../armA.json
cd armB && claude -p "<과제>" --output-format json > ../armB.json

# 트랜스크립트에서 usage를 합산해 비교
```
